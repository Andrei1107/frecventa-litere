# Analiza Frecvenței Literelor

Aplicație pentru calculul statistic al frecvenței literelor în texte (.txt, .pdf, .docx, .doc etc.), verificarea legii numerelor mari și comparație între două texte.
Backend: Spring Boot 3 + Apache Tika
Frontend: React + Vite + Chart.js
